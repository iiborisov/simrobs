# Dynamics of a planar 2R robot — interactive slides

Open [index.en.html](index.en.html) in a modern browser. The presentation works offline: CMU fonts, KaTeX, simulation code and recordings are bundled locally.

Use the on-screen navigation or arrow keys to change slides. Interactive controls on individual slides change model parameters and plots. See the [90-minute teaching plan](TEACHING_PLAN.en.md) and [lecture notes](../lecture_notes.en.md) for derivations, exercises and Python commands.
