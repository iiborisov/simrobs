# Control of a 2R robot — examples

These Python examples are shared by the Russian and English lectures. See the [English lecture notes](lecture_notes.en.md) for the model, equations, installation requirements, executable commands, expected results and interpretation of the experiments.

Run module commands from the repository root. Direct script commands shown in the lecture can also be run using absolute paths. Use a Python environment with the dependencies listed in [the original example guide](README.md). MuJoCo examples require MuJoCo; plots require Matplotlib.
