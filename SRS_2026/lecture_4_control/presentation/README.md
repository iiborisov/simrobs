# Презентация: управление 2R

Откройте `index.html` в современном браузере. Всё встроено: CMU Serif с кириллицей, KaTeX, математические шрифты и записи MuJoCo. Интернет нужен только при переходе к внешним источникам. Белый фон, чёрный текст, бордовые, оранжевые и бледно-голубые акценты соответствуют предыдущим лекциям.

- Стрелки / PageUp / PageDown — слайды; Home / End — начало/конец.
- O — обзор; F — полный экран; пробел — пауза/пуск видимого MuJoCo-проигрывателя.
- В лабораториях двигайте ползунки. В записях выбирайте регулятор и время.
- «Увеличить» открывает рисунок; Esc закрывает диалог.
- Переполненный по высоте слайд прокручивается внутри. Учтён системный режим уменьшенного движения: анимации изначально стоят на паузе.
- Печать браузером показывает все слайды. Ответы к вопросам раскройте перед печатью.

[Поминутный план](TEACHING_PLAN.md) рассчитан на 90 минут с обсуждениями. Конспект содержит полный вывод и упражнения; презентация служит сопровождением занятия.

Робот и результаты сравнения — записанные прогоны MuJoCo, не браузерная физика. Полные данные получаются запуском Python-примеров. Встроенная в HTML запись хранит каждый десятый шаг (20 мс); метрики рассчитаны по полным записям (2 мс). Выбор времени проигрывателя использует ближайший предыдущий сохранённый отсчёт. Лаборатории ошибки, статического равновесия и admittance-фильтра — отдельные аналитические демонстрации, что подписано на слайдах.
