# Масса–пружина–демпфер: сравнение интеграторов

Учебные скрипты к [конспекту лекции, разделы 9–10](../lecture_notes.md#10-практикум-три-python-метода-на-одной-системе). Исходный пример: [modeling_n_simulation.ipynb](../../../SRS/lecture_1/modeling_n_simulation.ipynb).

Модель: `m*x'' + b*x' + k*x = force - m*g`. Координата направлена вверх; ноль соответствует недеформированной пружине. Состояние — положение и скорость. Вход `force` постоянен. **Во всех трёх сценариях включена гравитация: `g=9.8` м/с².** В сценариях `undamped` и `stiff` начальное положение на 1 м выше гравитационного равновесия `x_eq=-m*g/k`; энергия рассчитывается относительно него. **Во всех трёх сценариях включена гравитация: `g=9.8` м/с².** В сценариях `undamped` и `stiff` начальное положение на 1 м выше гравитационного равновесия `x_eq=-m*g/k`; энергия рассчитывается относительно него.

## Запуск

Python 3.9 или новее. Поддерживаются прямой запуск файлов (в том числе Run в IDE) и запуск через `-m` из корня репозитория. Например:

```bash
python3 SRS_2026/lecture_1_modelling_n_simulation/mass_spring_damper/experiments.py
```

Запуск модулей из корня репозитория:

```bash
# Каждый метод отдельно; таблицы и CSV не требуют установки пакетов.
python3 -m SRS_2026.lecture_1_modelling_n_simulation.mass_spring_damper.forward_euler
python3 -m SRS_2026.lecture_1_modelling_n_simulation.mass_spring_damper.backward_euler
python3 -m SRS_2026.lecture_1_modelling_n_simulation.mass_spring_damper.rk4

# Общее сравнение на всех сценариях.
python3 -m SRS_2026.lecture_1_modelling_n_simulation.mass_spring_damper.experiments --scenario all
```

Для графиков установите matplotlib в своём окружении:

```bash
python3 -m pip install -r SRS_2026/lecture_1_modelling_n_simulation/mass_spring_damper/requirements.txt
python3 -m SRS_2026.lecture_1_modelling_n_simulation.mass_spring_damper.experiments --scenario all --plot
```

Можно создать отдельное окружение через `python3 -m venv .venv` и активировать его перед установкой. Параметры команд доступны через `--help`.

```bash
# Сходимость на мелкой сетке.
python3 -m SRS_2026.lecture_1_modelling_n_simulation.mass_spring_damper.experiments --scenario notebook --steps 0.01 0.005 0.0025 --duration 2 --plot

# Разрешение быстрого процесса в жёсткой задаче.
python3 -m SRS_2026.lecture_1_modelling_n_simulation.mass_spring_damper.experiments --scenario stiff --steps 0.001 0.0005 --plot
```

## Эксперименты

| Сценарий | Что показывает |
|---|---|
| `notebook` | Исходная вертикальная система; при крупных шагах явный Эйлер разгоняет физически затухающую систему |
| `undamped` | Точная энергия относительно равновесия постоянна; прямой Эйлер добавляет энергию, обратный — отнимает; RK4 намного точнее на выбранной сетке |
| `stiff` | При крупных шагах даже RK4 неустойчив; обратный Эйлер устойчив, но начальная быстрая динамика требует мелкой сетки для точности |

Результаты находятся в `results/` рядом со скриптами или в каталоге `--output`. Повторный запуск перезаписывает файлы с теми же именами. PNG содержит три панели: положение, скорость, энергия. Шкала `symlog` помогает увидеть и обычные колебания, и численное расхождение. Это не линейная шкала амплитуд.

Каждый CSV содержит время, численные положение и скорость, их точные значения и две энергии. Сводные файлы `summary_*.csv` содержат максимальные ошибки на узлах расчётной сетки и отношение конечной энергии к начальной. Ошибки имеют физические единицы; положение и скорость не складываются в одну размерную норму. При нулевой начальной энергии её отношение обозначается `nan`.

Уменьшение шага внутри области неустойчивости не обязано улучшать результат. Обратный Эйлер решается по точной линейной формуле: сходимость итераций здесь не ограничивает шаг. RK4 делает четыре вычисления правой части за шаг, прямой Эйлер — одно; для обратного используется отдельная алгебраическая формула. Число шагов и порядок точности сами по себе не определяют время вычисления.
