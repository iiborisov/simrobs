# Презентация: пространственная динамика

`index.html` — автономная презентация, 47 слайдов на 90 минут. Белый фон, чёрный текст, акценты, CMU Serif, KaTeX и математические шрифты встроены. Интернет нужен только при открытии внешних источников.

Стрелки / PageUp / PageDown — переходы; Home / End — начало/конец; O — обзор; F — полный экран. Пробел запускает/останавливает видимую запись. Все анимации изначально остановлены. Ползунки меняют аналитические модели; сцены вращаются мышью/пальцем. «Увеличить» открывает рисунок, Esc закрывает диалог. Длинные слайды прокручиваются внутри страницы.

Интерактивные части: гироскопический момент и его нулевая мощность; свободное вращение вокруг трёх главных осей; эллипсоид постоянной кинетической энергии; знак внешней силы и момента удержания; пять динамических опытов 3R.

Проигрыватель 3R содержит **реальные записи MuJoCo**, каждый десятый шаг (20 мс) из расчёта с шагом 2 мс. Метрики рассчитаны по полным записям. Выбранное время округляется к предыдущему сохранённому отсчёту. Свободное тело записано из отдельного Python-решения уравнений Эйлера. Ползунки инерции и gyro — аналитические вычисления в браузере.
